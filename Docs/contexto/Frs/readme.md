# Frs (Functional Requiremets)
<p>En esta seccion encontraremos el apartado de los requisitos funcionales de la aplicacion web.</p>

1. El sistema debera permitir el inicio y cierre de sesión para los usuarios autorizados (administrador y cajera(o)) garactizando el acceso segun su rol.

2. El sistema debera permitir la gestión de usuarios, incluyendo el registro, modificación, consulta y eliminación de cuentas de administrador y cajeras(os).

3. El sistema debera permitir la administracion del catalogo de productos, registrando cortes de carne con información como nombre, categoria, precio y existencia.

4. El sistema debera permitir la gestion de categorias para organizar los productos de manera clara y facilitar su busqueda.

5. El sitema debera permitir el control de inventario, actualizando automaticamente las existencias al realizar una venta.

6. El sistema debera permitir el registro de clientes, incluyendo la captura, edición, consulta y eliminación de sus datos.

7. El sistema debera permitir el registro de ventas, permitiendo a la o el cajero(a) agregar productos, calcular el total y finalizar la trasacción.

8. El sistema debera permitir la aplicacion de promociones y descuentos durante el proceso de venta, cuando esten vigentes.

9. El sistema deberá permitir la consulta del historial de ventas, para fines de control y toma de 
decisiones. 

10. El sistema deberá permitir la administración de recetas, permitiendo registrar, editar y eliminar 
recetas relacionadas con los productos de la carnicería. 

11. El sistema deberá permitir la gestión de promociones y novedades, las cuales podrán ser 
visibles para los clientes.

12.  El sistema deberá permitir la búsqueda y filtrado de información, tanto de productos como de 
clientes y ventas. 

13.  El sistema deberá mostrar mensajes de confirmación y error, informando al usuario sobre 
acciones realizadas correctamente o errores en el sistema. 

14. El sistema deberá permitir la navegación entre módulos, facilitando el acceso a las diferentes 
secciones de la aplicación.
