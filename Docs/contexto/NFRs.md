# Requerimientos no funcionales


1. Usabilidad:
El sistema deberá contar con una interfaz intuitiva y fácil de usar, de manera que los usuarios
puedan realizar sus actividades sin necesidad de capacitación avanzada.

2. Rendimiento:
La aplicación deberá responder a las acciones del usuario en un tiempo máximo aceptable, incluso
cuando existan varios registros de productos, clientes o ventas.

3. Seguridad:
El sistema deberá proteger la información mediante autenticación de usuarios, manejo seguro de
contraseñas y control de accesos según el rol del usuario.

4. Disponibilidad:
La aplicación deberá estar disponible durante el horario de operación de la carnicería, reduciendo
al mínimo los tiempos de inactividad.

5. Compatibilidad:
El sistema deberá ser compatible con los navegadores web más utilizados, permitiendo su correcto
funcionamiento en computadoras y tabletas.

6. Escalabilidad:
La aplicación deberá permitir la incorporación futura de nuevos módulos o funciones sin afectar su
funcionamiento actual.

7. Mantenibilidad:
El sistema deberá estar desarrollado de forma organizada y documentada, facilitando su
mantenimiento y actualización.

8. Confiabilidad:
La aplicación deberá garantizar que la información registrada sea consistente y que las operaciones
se completen correctamente.

9. Accesibilidad:
La interfaz deberá utilizar colores legibles, tamaños de letra adecuados y un diseño que facilite el
uso a distintos tipos de usuarios.

10. Respaldo de información:
El sistema deberá permitir la realización de respaldos periódicos de la base de datos para evitar la
pérdida de información.
