# Historias de usuario (User Stories)

| **ID US** | **Prioridad** | **COMO (tipo de usuario)** | **QUIERO (realizar una tarea)**	| **PARA QUE PUEDA (el logro de algun objetivo)** |	
|-----------|---------------|----------------------------|----------------------------------|-------------------------------------------------|		
| **US-01**	| Alta | Como administrador y/o cajero. | Quiero iniciar sesión al ingresar en el sistema. | Para que pueda acceder a las funciones correspondientes según sea mi rol. |	
| **US-02**	| Alta | Como administrador. | Quiero modificar, registrar y eliminar productos. | Para que pueda mantener actualizado de los cortes de carne. |
| **US-03**	| Alta | Como administrador. | Quuiero administrar las categorias de los productos. | Para que pueda organizar mejor los cortes de carne. |												
| **US-04**	| Alta | Como adminstrador. | Quiero consultar y actualizar el inventario. | Para que pueda asegurar que las existencias esten correctas y evitar faltantes. |												
| **US-05**	| Media | Como cajero(a). | Quiero consultar y registrar clientes. | Para que pueda agilizar la atencion y llevar un mejor control de las compras.	|												
| **US-06**	| Alta | Como cajero(a). | Quiero registrar una venta selccionando peoductos y cantidades. | Para que pueda calcular el total y completar la trasaccion correctamente. |												
| **US-07**	| Media | Como cajero(a). | Quiero aplicar promociones y descuentos vigentes durante la venta. | Para que pueda ofrecer mejores precios a los clientes 	|												
| **US-08**	| Media | Como administrador. | Quiero consultar el historial de la ventas. | Para que pueda analizar el desempeño del negocio. |												
| **US-09**	| Baja | Como administrador. | Quiero actualizar y registrar nuevas recetas. | Para que pueda compartir ideas con los clientes de preparación carnica.|										
| **US-010** | Baja | Como administrador. | Quiero admistrar promociones y las nuevas novedades. | Para que pueda informar a los clientes sobre los descuentos y eventos importantes. |													
| **US-011** | Alta | Como cliente. | Quiero navegar facilmente entre los modulos que se encuentran. | Para que pueda realizar las tareas de forma rapida y ordenada. |
