# Historias de usuario


### HU-01: Inicio de sesión
Como administrador o cajera(o),
quiero iniciar sesión en el sistema,
para acceder a las funciones correspondientes según mi rol.

### HU-02: Gestión de productos
Como administrador,
quiero registrar, modificar y eliminar productos,
para mantener actualizado el catálogo de cortes de carne.

### HU-03: Gestión de categorías
Como administrador,
quiero administrar las categorías de productos,
para organizar mejor los cortes de carne y facilitar su búsqueda.

### HU-04: Control de inventario
Como administrador,
quiero consultar y actualizar el inventario,
para asegurar que las existencias estén correctas y evitar faltantes.

### HU-05: Registro de clientes
Como cajera(o),
quiero registrar y consultar clientes,
para agilizar la atención y llevar un mejor control de sus compras.

### HU-06: Registro de ventas
Como cajera(o),
quiero registrar una venta seleccionando productos y cantidades,
para calcular el total y completar la transacción correctamente.

### HU-07: Aplicación de promociones
Como cajera(o),
quiero aplicar promociones y descuentos vigentes durante la venta,
para ofrecer mejores precios a los clientes.

### HU-08: Consulta de ventas
Como administrador,
quiero consultar el historial de ventas,
para analizar el desempeño del negocio.

### HU-09: Gestión de recetas
Como administrador,
quiero registrar y actualizar recetas,
para compartir ideas de preparación con los clientes.

### HU-10: Gestión de promociones y novedades
Como administrador,
quiero administrar promociones y novedades,
para informar a los clientes sobre descuentos y eventos importantes.

### HU-11: Navegación del sistema
Como usuario del sistema,
quiero navegar fácilmente entre los módulos,
para realizar mis tareas de forma rápida y ordenada.
