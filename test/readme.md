## Descripción
Para garantizar que la aplicación de la carnicería funcione de manera óptima y sin errores en los procesos de venta e inventario, se implementó un protocolo de QA (Quality Assurance). Este apartado se centra en validar la estabilidad de las herramientas administrativas mediante:

10 Test Documentados: Se realizaron pruebas exhaustivas sobre los flujos críticos, como el registro de nuevos cortes de carne, la actualización de precios y el inicio de sesión seguro. Cada prueba describe el escenario, los datos de entrada y la verificación del resultado esperado para asegurar una experiencia sin fallos para cajeros y administradores.

Validación de Procesos: Estas pruebas aseguran que el control de existencias y el registro de clientes sean precisos, evitando errores humanos en la gestión del stock

## Tecnologías
- Jira: Control de flujo de trabajo y gestión de tareas ágiles.
- QMetry: Documentación, ejecución y seguimiento de casos de prueba.
- Excel: Matrices de datos iniciales y control de documentación técnica.

## Estructura
- Verificar carga de la página principal antes de iniciar sesión
- Validar acceso al formulario de registro
- Validar registro de nuevo usuario con datos correctos
- Validar mensaje de error en registro con campos vacíos
- Validar acceso al formulario de inicio de sesión
- Validar inicio de sesión con credenciales correctas
- Validar mensaje de error con contraseña incorrecta
- Validar opción de recuperación de contraseña
- Validar envío de enlace de recuperación de contraseña
- Validar restablecimiento de contraseña
- Validar acceso al catálogo de productos
- Validar visualización de productos en catálogo
- Validar navegación dentro del catálogo
- Validar restricción de acceso a usuarios no autenticado
- Validar funcionamiento completo del sistema
